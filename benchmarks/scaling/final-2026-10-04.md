# Completed-count switch, 0.4.0

**BLOCKED: do not merge or tag this head.** The default is restored to 1,000
completed usable observations, but the final sampler misses both revised
long-budget geomean gates. At 3k it also misses the rotated-ellipsoid per-problem
gate. Native and sanitizer quality tests pass without weakening any threshold.

All compilation, tests, profiles, and numerical aggregation use one AWS
c6i.2xlarge Linux spot machine: 8 vCPU, GCC 13.3, C++17 Release. Timing probes
share the box with gate work; these are contended measurements, not isolated
peak-throughput claims. The branch is rebased onto 0.3.1 (`13885b9`), with
unchanged engine/codegen gitlinks. The small CSVs and verified SHA-256 metadata
are under `benchmarks/optuna/evidence/2026-10-04-final-1000-*`.

## Design and exact prefix

Below 1,000 successful finite `tell()` observations, use the exact 0.3.0 model.
At that completed count, switch to the unchanged round-one bounded estimator:
25 elites, 64 recent non-elites, 448 independently seeded older non-elites,
elite-triggered good-model refresh, bad-model refresh every 32 completions,
513-point density tables, eight EI draws, and live pending-liar overlays.
Issued, pending, failed, pruned, or abandoned proposals do not advance the switch.
`--tpe-history-switch N` and StudySpec `sampler.config.history_switch` preserve
the override; `tpe_history_switch` remains recorded in results and terminal records.

Prefix identity compares IDs, every parameter byte, and hexadecimal objective
values against pinned 0.3.0: **80 studies x 1,000 proposals, diff count 0**.
Another 16 override-prefix studies compare 256 proposals with N=512. Combined:
**96 studies, 84,096 proposal/value records, diff count 0**. This proves prefix
identity, not long-budget quality parity. Production replay also covers W1/W8,
lag0/lag1, and none/median pruning through 3,000 trials.

A larger override retains legacy behavior longer, but increases prefix memory
and history-growing ask cost. Historical random-prefill legacy 16D snapshot
probes measured 27,652 us/ask at 1,024 observations and 112,201 at 4,096. There
is no per-dimension budget used to select the default switch.

## Contract changes in 0.4.0

Schema version stays 1; no existing terminal fields or billing-counter types
change. Additive switch/configuration and output-retention metadata are documented
in `docs/api.md`. Progress remains the full billing record regardless of
`--trials-out all|best-k|none` or optional `--trials-file`; `all` remains the
compatibility default. Dropped lists retain summary counts, best-k, and coverage.
The default switch changes from the provisional 8 to 1,000; CLI/StudySpec
overrides and recorded `tpe_history_switch` stay supported. Native `prepare`
remains a separately gated 0.4.x follow-up, not part of this blocked release.
